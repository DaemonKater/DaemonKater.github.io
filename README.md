# Вкусный Ташкент — гастрономический путеводитель

Полностью готовый статический сайт на HTML, CSS и JavaScript. Серверная часть и база данных не нужны. Контент, изображения и интерактивные разделы находятся в папке проекта.

## Быстрый запуск

1. Распакуйте ZIP-архив.
2. Откройте `index.html` в браузере. Для интерактивной карты нужен интернет.
3. Для публичной ссылки разместите **содержимое архива** на Netlify, Cloudflare Pages, GitHub Pages или другом статическом хостинге. `index.html` должен быть в корне сайта.

Для локальной проверки через HTTP: `python -m http.server 8000` в каталоге сайта и затем `http://localhost:8000/`.

## Возможности

- Шесть тематических гастропрогулок по Ташкенту с описаниями и маршрутными PDF.
- **Многодневный конструктор:** готовые варианты на 1–5 дней; 17 точек по городу; выбор и перенос остановок между днями, изменение порядка, приблизительная сортировка по расстоянию.
- Дополнительное поле для ввода начального адреса или отеля (необязательно; не сохраняется).
- Рекомендации для каждой локации: что посмотреть, что попробовать, на что обратить внимание, ссылка на источник и отдельная навигация.
- Отдельная картографическая секция с картой остановок, маркерами, переключением обычного/спутникового вида. Для автомобильного режима предпринимается попытка проложить путь по дорогам через OSRM. Для пешего режима показывается **условная последовательность точек**, а реальная пошаговая навигация строится при открытии Google Карт.
- Возможность открыть маршрут дня в Google Картах; для очень длинных поездок доступно разделение на последовательные этапы и отдельные переходы между каждой парой остановок. Поддерживаются пеший и автомобильный режимы.
- Скачиваемый **многостраничный PDF с оформлением в узбекском стиле** и кликабельными ссылками на навигацию. Если в один день добавлено много мест, PDF разделит их на несколько страниц с общими остановками на границах этапов.
- Гастрономическая энциклопедия: 19 блюд, напитков и сладостей, категории, поиск, фотографии и рекомендации по подаче.
- Интерактивный **дастархан**: авторская круговая сцена из восьми блюд с переключением карточек (не VR и не документальная панорама).
- Сувенирная мастерская: персональная открытка с фотореалистичным изображением плова, гастропаспорт или билет. Предпросмотр и загрузка PNG, возможность поделиться через меню устройства.
- Адаптивный дизайн, анимации с учётом `prefers-reduced-motion` и локальные изображения WebP.

## Где редактировать

- `index.html` — секции и навигация.
- `css/style.css` — дизайн и адаптивность.
- `js/app.js` — короткие туры, карта тематических маршрутов, викторина и их PDF.
- `js/explorer.js` — 17 мест, многодневный конструктор, справочник 19 блюд, интерактивный дастархан и многодневные PDF.
- `js/souvenir.js` — персональные сувениры, генерация PNG.
- `assets/photos/` — локальные WebP-изображения.

## Публикация и картография

Сайт рассчитан на работу по публичному HTTPS-адресу. Карта использует Leaflet, стандартную подложку OpenStreetMap и спутниковую подложку Esri. Основная карта не требует API-ключа. При проблемах с подложкой остаются рабочие переходы в Google Карты. Маршрутизация OSRM — это сторонний демонстрационный сервис: работа с ним не гарантируется, особенно при высокой нагрузке; подробная навигация производится непосредственно в Google Картах.

На публичном сайте с существенным трафиком рекомендуется использовать специализированного провайдера картографических подложек и маршрутизации с подходящими условиями использования. Пользовательское поле «Откуда начинаешь?» не сохраняется в LocalStorage; маршрутные планы на 1–5 дней сохраняются только в браузере пользователя, не отправляются на сервер.

Фотографические изображения еды и города — специально созданные **художественные иллюстрации**. Они не являются документальными фотографиями конкретных ресторанов, а изображения в карточках городских объектов показывают атмосферу Ташкента, а не обязательно фасад указанного места. В карточках каждой локации имеется ссылка на информацию о ней. Рекомендуется уточнять часы работы, доступность и цены непосредственно перед поездкой.
