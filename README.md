# Вкусный Ташкент — версия 9.0 · Motion / 360° / WebAR

Интерактивный гастрономический путеводитель по Ташкенту. Проект — статический сайт: HTML, CSS и JavaScript, без бэкенда и регистрации.

## Запуск и публикация

Для проверки обычной страницы можно открыть `index.html`, однако **AR и некоторые функции датчиков требуют HTTPS**. Для публичной версии загрузите всё содержимое ZIP в корень Cloudflare Pages, Netlify, GitHub Pages или другого HTTPS-хостинга. Не загружайте лишь `index.html`: видео, панорамы и GLB лежат в `assets/`.

## Что действительно работает

- **Видеозаставка:** локальный MP4 из художественных иллюстраций с движением камеры и реальными видеокадрами для онлайн-воспроизведения, когда доступен Wikimedia Commons. Отдельное окно «Смотреть реальные кадры» показывает документальную 3,7-секундную съёмку традиционного базара Узбекистана. *Это не подтверждённо Чорсу.* Если источник недоступен, можно выбрать локальный монтаж. Источник указан ниже.
- **360°:** сферический просмотр реальных 360°-фото **снаружи и внутри Государственного музея истории Узбекистана в Ташкенте**. Доступны перетаскивание панорамы, изменение направления взгляда, приближение колёсиком, кнопка гироскопа (при поддержке и разрешениях), полноэкранный режим, просмотр для двух глаз простых VR-очков. Режим очков использует однокамерную сферическую фотографию; это **не стереоскопическая 3D-съёмка**, и по сцене нельзя свободно ходить. Для WebGL с ограничениями есть упрощённый панорамный разворот. При недоступности внешнего оригинала показывается **отдельно обозначенный художественный** локальный запасной вариант.
- **3D и AR:** оригинальная объёмная модель традиционной стилизованной узбекской пиалы с чаем (`assets/models/uzbek_piyala.glb`), просмотр и вращение с помощью `model-viewer`. На совместимых мобильных устройствах и HTTPS можно запросить AR (WebXR / Android Scene Viewer / iOS Quick Look, если среда поддерживает). **AR не гарантируется на каждом устройстве.** Если внешний движок 3D не загрузился, включается локальное видео вращения настоящей модели; этот запасной режим не выдаётся за AR.
- **Остальные функции** сохранились: 6 готовых маршрутов, конструктор на 1–5 дней с 17 местами, PDF-путеводитель, энциклопедия 19 блюд, интерактивный дастархан, сувениры в PNG и карта с переходом к дорожной навигации.

## Структура

- `index.html` — интерфейс.
- `css/style.css`, `css/v7.css`, `css/immersive-v9.css` — оформление.
- `js/app.js`, `js/explorer.js`, `js/souvenir.js`, `js/immersive-v9.js` — логика.
- `assets/video/tashkent-cinematic.mp4` — локальная динамическая видеозаставка из художественных кадров.
- `assets/video/piyala-turntable.mp4` — видео вращения исходной 3D-геометрии пиалы (резервный режим просмотра).
- `assets/models/uzbek_piyala.glb` — физическая 3D-модель для WebAR.
- `assets/vr/artistic_panorama.webp` — запасной художественный сферический предпросмотр, не документальная съёмка.
- `assets/photos/` и `assets/places/` — локальные изображения.
