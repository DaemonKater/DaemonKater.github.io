# Вкусный Ташкент

Гастрономический путеводитель по Ташкенту: шесть маршрутов, настоящая карта города, интерактивные истории о блюдах и мастерская цифровых сувениров.

Сайт полностью статический. Для размещения достаточно HTML, CSS и JavaScript — серверная часть, база данных и сборка не нужны.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере с доступом к интернету.
3. Для публикации загрузите **содержимое папки** на любой статический хостинг. Файл `index.html` должен лежать в корне опубликованного сайта.

Если хотите запустить локальный HTTP-сервер: `python -m http.server 8000`, затем перейдите на `http://localhost:8000`.

## Размещение по публичной ссылке

**Netlify Drop:** откройте https://app.netlify.com/drop, перетащите распакованную папку сайта и получите публичный адрес.

**Cloudflare Pages:** создайте проект с Direct Upload и загрузите папку с `index.html`, `css/`, `js/` и `assets/`.

**GitHub Pages:** загрузите содержимое папки в репозиторий, затем включите Pages для основной ветки. Важно, чтобы `index.html` находился в корневой папке публикации.

Все пути к файлам относительные, поэтому домен настраивать не требуется. После публикации желательно проверить на смартфоне карту, ссылки навигации и загрузку PDF.

## Возможности

- Шесть тематических гастромаршрутов с карточками и расширенными программами;
- фильтры по интересам и быстрый мини-тест для подбора маршрута;
- полноценная карта Ташкента с остановками, маркерами, масштабированием, обычным и спутниковым видами;
- переход к навигации по всему маршруту и к выбранной точке в Google Картах;
- отображение последовательности остановок и возможность открыть маршрут для навигации в Google Картах;
- **скачивание аккуратно оформленного PDF A4** для каждого маршрута со списком остановок и кликабельной ссылкой на навигацию;
- мастерская сувениров: **открытка**, **гастропаспорт**, **билет на вкус**, четыре цветовых оформления, персональная подпись, значки за попробованные блюда;
- создание изображения сувенира в браузере и загрузка в PNG; отправка через системное меню «Поделиться» на совместимых устройствах;
- адаптивная верстка, анимации, иллюстрации узбекских блюд, удобное меню для смартфонов.

## Содержание и маршруты

Данные маршрутов, точки на карте и тексты редактируются в `js/app.js`. Мастерская сувениров — `js/souvenir.js`. Стили — `css/style.css`, векторная графика — `assets/`.

Маршруты являются рекомендациями для самостоятельного знакомства с городом, а не предложениями купить билет. Длительность ориентировочная. Заведения и их часы работы могут меняться; перед посещением проверяйте актуальную информацию. Длинные маршруты требуют переездов. Для пешеходной навигации ориентируйтесь по ссылкам Google Карт, а не по прямым пунктирным линиям между точками.

## Внешние сервисы и лицензии

- [Leaflet](https://leafletjs.com/) — подключается до приложения с Cloudflare CDN. При недоступности применяется интерактивная карта Google Maps.
- [OpenStreetMap](https://www.openstreetmap.org/copyright) и CARTO Voyager — основной уличный слой; резервные OpenStreetMap и Esri Street Map.
- [Esri World Imagery](https://www.esri.com/) — спутниковый слой.
- [Google Maps](https://www.google.com/maps) — внешняя навигация.
- [OSRM](https://project-osrm.org/) — опциональное отображение автомобильного пути **через публичный демонстрационный сервер**, который может иметь ограничения и не гарантирует доступность. Для высокопосещаемого публичного проекта нужен собственный или коммерческий роутинг; основной функционал не зависит от OSRM.
- Фотографические иллюстрации еды и атмосферы — локальные файлы в `assets/photos/`; они созданы специально для дизайна и не отображают конкретные заведения.
- Google Fonts — веб-шрифты.

Для интерактивной карты и веб-шрифтов требуется интернет. Фотографии встроены в архив и показываются независимо от сети; карта автоматически переключается между поставщиками подложки и при сбое использует Google Maps iframe. Генерация PDF и PNG происходит локально в браузере; имя для сувенира не отправляется на сервер. Загрузка сувениров и маршрутных листов не требует передачи персональных данных.
